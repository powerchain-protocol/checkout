# Security policy

Do not open public issues for vulnerabilities involving private-key exposure, signature bypasses, token-account validation, replay protection, fee diversion, oracle manipulation, or program authority controls.

Report vulnerabilities privately through GitHub Security Advisories for this repository.

## Supported versions

Only the latest minor release is supported before the first stable `1.0.0` release.

## Mainnet notice

The programs and SDK must be independently audited before production deployment. Never use development keypairs or browser-exposed privileged API keys on mainnet-beta.
