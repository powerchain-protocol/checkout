# Contributing

## Setup

```bash
git clone https://github.com/powerchain-protocol/powerpay-checkout-sdk.git
cd powerpay-checkout-sdk
npm install
npm run check
```

Solana program work also requires Rust and the Solana SBF toolchain.

## Branches and commits

Create focused branches and keep commits reviewable. Update tests and documentation with behavior changes.

## Pull requests

All pull requests should pass SDK checks, Rust formatting/tests, metadata validation, and documentation checks. Changes to account layouts or instruction encodings must include migration notes.
